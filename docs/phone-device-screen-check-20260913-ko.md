### 미해결 문제의 재현 근거

타이머 실행 화면의 '다른 시간으로 변경' 아래 영역에서 버튼 4개 전체가 빈 공간으로 보인다. UI XML에는 정상 bounds, 아이콘·텍스트, 활성 클릭 대상이 남아 있고 해당 위치를 누르면 직접 입력 창이 열린다. 23분 변경·일시정지/재개·탭 왕복·스크롤 이후에도 사라진 상태가 지속됐다.

대기 화면의 파란 기본 버튼은 정상이며 실행 화면의 투명 `ghost` 버튼에서 문제가 관찰됐다. 코드상 `overflow: hidden`과 Android ripple/drawable 경계 조합이 의심되지만 **원인 확정이나 수정 완료가 아니다**. 후속 수정에서는 이 버튼만 `secondary` 스타일로 바꾸는 비교와 ghost 클리핑 조건 비교를 분리해 확인한다.

## 로컬 증거

모든 캡처는 `.artifacts/phone-screen-check-20260913/`의 PNG/XML 쌍으로 보관한다. 화면 이름보다 실제 PNG와 XML을 기준으로 판단했다. XML과 PNG는 순서대로 수집했으며 같은 프레임을 보장하지 않는다.

- `play-baseline`: 기존 Play 앱 하단 잘림.
- `check-today-108`, `check-calendar-108`, `check-settings-108`, `check-final-timer-idle`: 기본 글자 화면.
- `check-settings-140`, `check-settings-200`: 파일명과 달리 **Today**. 글자 크기 변경 시 Activity가 Today로 복원됐다.
- `check-timer-200`, `check-wheel-200`, `check-numeric-200`, `check-numeric-back-200`: 큰 글자 타이머/키보드.
- `check-numeric-empty-108`, `check-input-zero`, `check-input-61`, `check-input-1`, `check-input-60`: 숫자 경계/오류 입력.
- `check-wheel-after-swipe`: 스와이프 15→23분.
- `check-wheel-open-108`: 파일명과 달리 **30분 실행 상태**. 버튼 사라짐 최초 캡처.
- `check-changed-23`, `check-paused-23`, `check-timer-return-23`, `check-timer-scroll-23`: 변경/정지/복귀 시 시간 표시와 보이지 않는 버튼.
- `check-battery-app-details`, `check-battery-options`: 패키지 전용 Android 설정.

UI 트리에 문구가 존재한다는 사실만으로 실제 화면 표시를 합격 처리하지 않았다. TalkBack 실제 낭독, 관성 스크롤 프레임 성능, 진동 횟수, 알람 만료 음향, 위젯, Play 업데이트 보존 검사는 이번에 하지 않았다.
