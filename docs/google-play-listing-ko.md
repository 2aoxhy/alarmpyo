## 짧은 설명

주간·교대 근무표와 기상 알람을 한눈에 관리하세요.

## 전체 설명

알람표는 교대 근무자와 주간 고정 근무자를 위한 일정·알람 앱이에요.

복잡한 근무 순서를 달력에서 한눈에 확인하고, 다음 근무에 맞는 기상 알람과 수면 준비 시점을 확인할 수 있어요. 로그인 없이 근무표와 설정을 휴대전화 안에 저장해요.

주요 기능

- 3조 2교대 주주야야휴휴와 주간 고정 근무표 지원
- 주간·야간·대체근무·교육·예비군 일정 관리
- 앱이 닫혀 있어도 작동하도록 설계한 근무 기상 알람
- 5분 후 한 번 더 울리는 기본 재알림
- 다음 근무와 남은 시간을 보여주는 홈 화면 위젯
- 법정공휴일과 급여일을 함께 보여주는 근무 달력
- 교대 흐름을 고려한 수면 준비 시점 안내
- 근무 설정 공유와 암호화 백업·복구
- 라이트·다크 테마와 큰 글자 지원

알람표는 회사 공식 앱이 아니며 특정 회사의 근무·보안 시스템에 연결되지 않아요. 근무표와 개인 메모는 사용자가 공유 또는 백업을 직접 선택하지 않는 한 기기 밖으로 전송하지 않아요.

수면 준비 시점 안내는 근무 일정 관리를 돕는 일반적인 참고 정보이며 의료기기가 아니에요. 진단·치료 또는 의료 전문가의 조언을 대신하지 않아요.

## 그래픽 자료

최종 업로드에는 AlarmPyo 계보 자산을 사용해요.

- 최종 512×512 아이콘: `assets/play-store/alarmpyo-icon-512.png`
- 최종 1024×500 대표 그래픽: `assets/play-store/alarmpyo-feature-graphic.png`
- 앱 아이콘 파생 자산: `assets/images/alarmpyo-*.png`
- 휴대전화 스크린샷: 현재 릴리스 후보를 **Play 내부 트랙으로 설치한 실제 Android 기기**에서 새로 촬영해요.

권장 스크린샷 순서

1. 오늘 근무와 다음 근무
2. 근무 달력
3. 알람 설정과 기상 시간
4. 수면 준비 시점 안내와 비의료 안내
5. 홈 화면 위젯

스크린샷은 현재 기능만 보여주고, 상태 표시줄의 개인정보·테스터 이메일·기기 식별 정보는 제거해요. 라이트·다크 테마 중 실제 가독성이 좋은 구성을 사용하되 화면을 합성해 존재하지 않는 기능을 만들지 않아요.

## 건강 기능과 계정 유형 결정

Google의 건강 앱 선언에는 `Sleep Management`가 별도 항목으로 있어요. 알람표의 수면 준비 시점 안내를 유지한다면 Play 지원의 다른 확인이 없는 한 이 항목으로 보수적으로 신고해요. 건강 데이터 수집 여부와 건강 기능 제공 여부는 별도 질문이므로, 데이터를 수집하지 않는다는 이유만으로 “건강 기능 없음”을 선택하지 않아요. [건강 앱 선언 공식 안내](https://support.google.com/googleplay/android-developer/answer/14738291?hl=ko)

2026년 9월 30일부터 적용되는 Play Console 요구사항에는 건강 앱 등 지정 서비스의 조직 계정 등록 요건이 있어요. production 전에 분류와 계정 유형을 확정하고, 필요한 경우 D-U-N-S와 조직 확인을 준비해요. [Play Console 요구사항](https://support.google.com/googleplay/android-developer/answer/10788890?hl=ko)

## 제출 전 Play Console 작업

1. 실제 지원 이메일·전화번호와 개발자 프로필 확인을 끝내요.
2. 개인정보 처리방침 주소가 로그인·지역 제한 없이 열리고 앱 안에서도 접근 가능한지 확인해요.
3. 데이터 보안 양식을 `docs/google-play-data-safety-ko.md`와 최종 AAB의 SDK·네트워크 동작에 맞춰 작성해요.
4. 건강 앱 선언과 `Sleep Management` 분류, 비의료 안내를 확정해요.
5. 정확한 알람, 전체 화면 알람, 포그라운드 미디어 재생 권한을 신고해요.
6. 실제 Samsung 기기에서 정확한 알람 예약, 앱 종료 상태 알람, 잠금 화면 전체 화면 표시, 알람음 종료를 순서대로 보여주는 검토 영상을 준비해요. FGS 유형별 기능 실행 과정이 분명하게 보여야 해요. [FGS·전체 화면 Intent 선언 안내](https://support.google.com/googleplay/android-developer/answer/13392821?hl=ko)
7. 콘텐츠 등급, 대상 연령, 광고 없음, 앱 액세스 불필요, 금융 기능 없음, 정부 앱 아님을 실제 동작과 맞게 답해요.
8. 첫 제출은 내부 테스트 초안으로 올리고, Play 생성 APK의 서명·실기기·16KB·사전 출시 보고서를 검증한 뒤 공개 범위를 결정해요.
9. 2023년 11월 13일 이후 만든 개인 계정이면 12명·14일 비공개 테스트 요건을 완료해요. [개인 계정 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)

- production Hosting URL 또는 AlarmPyo 앱 서명 인증서
- 첫 후보 `1.0.0(1)`과 Play Console의 비어 있는 새 package 계보 확인
- 권한·FGS 선언 영상, 데이터 보안, 개인정보 처리방침
- 실제 기기 스크린샷과 지원 연락처
- Play 생성 APK 실기기 QA, 16KB 환경, 사전 출시 보고서
