# V1.22 실기기 발견 사항의 코드 보완

2026-09-06. 기준 커밋 `91140c5` 이후의 코드 수정입니다. 버전은 1.22(22)를 유지하며 AAB 생성, EAS 작업, Play 업로드·배포 및 휴대폰 설치·설정 변경은 하지 않았습니다.

## 반영한 수정

### One UI 위젯 크기 분류

- 실제 Samsung 4×1 측정값(4열·1행, 약 401.07×100.27dp)을 회귀 입력으로 추가했습니다.
- 유효한 One UI 행·열 정보가 있고 1행이면 100dp 이상이어도 압축형을 선택합니다.
- Android 12 이상에서 `OPTION_APPWIDGET_SIZES`의 유효한 크기를 확인합니다. 단일 RemoteViews가 가능한 크기들에 들어가도록 최소 폭·높이를 사용합니다. 이 목록을 현재 화면의 단일 크기로 오해하지 않습니다. [Android 위젯 크기 API](https://developer.android.com/develop/ui/views/appwidgets/layouts)
- 빈 목록, 잘못된 타입·범위, NaN/무한대는 버리고 표준 min/max 크기 또는 기본값으로 돌아갑니다. One UI 정보가 없는 런처의 기존 공간 기반 정책은 유지합니다.
- 새 AndroidX 의존성 없이 Android 12부터 지원되는 플랫폼 Bundle API로 크기 목록을 읽고 각 항목을 `SizeF`로 확인합니다. 첫 컴파일에서 발견한 `BundleCompat` 미지원 문제도 이 방식으로 수정했습니다.
- 1행→2행→1행 전환, 실제 공간이 작은 2행, 115%·130~200% 글자를 검사합니다. snapshot v2와 네이티브 API·view ID·사용자 표시 설정은 바꾸지 않았습니다.

### 타이머 선택 버튼과 도움말 표시

- 대기·실행 상태의 프리셋을 `QuickTimerPresets`로 통합했습니다. 네 버튼을 명시적 1·2·4열로 배치하여 퍼센트 폭과 자동 줄바꿈의 조합을 제거했습니다.
- 타이머 화면과 직접 입력의 ScrollView에 `removeClippedSubviews=false`를 적용하고, 프리셋 행·범위·도움말의 native View 경계를 유지했습니다. 공통 Screen의 이 설정은 선택 사항이며 다른 화면의 기본 동작은 유지합니다.
- React Native 0.86 문서는 해당 clipping 옵션에서 콘텐츠가 사라질 수 있음을 경고합니다. 이번 조치는 그 위험을 줄이는 보완이며, 이것이 기존 V1.21 문제의 유일한 원인이었다고 단정하지 않습니다. [React Native ScrollView](https://reactnative.dev/docs/0.86/scrollview#removeclippedsubviews)
- 15·30·45분·직접 입력, 로딩/비활성 상태, 동작과 초점 반환 ref를 검사했습니다. 카운트다운 갱신 주기·기존 문구·버튼 스타일·네이티브 타이머 계약은 유지했습니다.

### 백그라운드의 지연 자동 점검

- 아직 실행되지 않은 500ms 자동 알람 점검은 앱이 비활성화되면 취소하고, 미처리 상태를 보존해 복귀 시 한 번 다시 예약합니다.
- 저장 큐에서 대기하던 자동 수면 점검은 시작 당시 foreground revision이 바뀌면 폐기합니다. stop/start 이전의 큐 작업도 새 세션에서 실행되지 않습니다.
- 백그라운드 진입 시 저장 flush와 사용자가 요청한 저장·알람 OFF·재시도는 유지합니다. 이미 `resyncAlarms()`에 전달되어 큐에서 기다리거나 진행 중인 작업, Android에 예약된 알람은 중단하지 않습니다.
- 기존 V1.21 CPU 과다 종료의 원인은 아직 미확정입니다. 이번 변경을 CPU 문제 해결의 실기기 증거로 간주하지 않습니다.

## 아직 남은 실기기 검증

휴대폰에는 이전에 확인한 Play V1.21만 있으며 이 코드 후보를 설치하지 않았습니다. V1.22 설치 후 다음을 확인해야 합니다.

1. 실행 중 타이머에서 프리셋 4개가 모두 표시되는지, 숫자 입력·스크롤·키보드·복귀 후 범위와 도움말이 남는지 확인합니다.
2. One UI 4×1↔4×2 크기 변경과 큰 글자에서 실제 위젯 레이아웃·잘림·접근성을 확인합니다.
3. 화면 비활성·장시간 백그라운드·복귀 후 CPU 사용과 알람/타이머 동작을 확인합니다.

이는 [V1.21 기준 점검](v1.22-samsung-baseline-20260906.md)에 대한 후속 코드 보완이며, V1.22 실기기 합격 또는 배포 완료 기록이 아닙니다.
