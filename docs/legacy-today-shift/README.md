# Today Shift legacy release archive

이 폴더는 AlarmPyo(`알람표`)와 별개인 이전 Today Shift/HTSA 계보의 릴리스 증거를 보존해요.

- 이 파일들은 과거 APK의 패키지, 서명 인증서, 해시와 배포 주소를 감사하기 위한 읽기 전용 자료예요.
- AlarmPyo 릴리스 스크립트는 이 폴더의 정책이나 원장을 읽지 않아요.
- 이전 인증서·버전 코드·원장 항목을 `com.personal.alarmpyo` 계보에 복사하지 않아요.
- 새 계보의 원장은 [`../release-ledger.json`](../release-ledger.json)에서 빈 상태로 시작해요.

보관된 자료:

- `release-ledger.json`: 이전 APK 원장
- `release-policy.json`: 이전 direct APK 서명 정책
- `play-release-policy.json`: 이전 Play 정책
- `redesign-baseline.md`: 이전 업데이트·데이터 호환 기준
- `ARCHIVE_INFO.txt`: 이전 소스 보관 정보
