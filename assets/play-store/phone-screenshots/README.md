# Google Play 휴대전화 스크린샷

현재 Play 내부 트랙의 릴리스 후보를 실제 Android 기기에 설치한 뒤 이 폴더에 새로 촬영한 이미지를 넣어요. 예시는 `01-today.png`, `02-calendar.png`처럼 노출 순서를 두 자리 숫자로 시작해요.

- 게시 최소: 2장, 최대 8장
- 권장: 1080×1920px 9:16 세로 이미지 4장 이상
- 형식: 채널당 8비트 RGB 3채널 JPEG 또는 알파 채널이 없는 비인터레이스 24비트 RGB PNG
- 허용 크기: 짧은 변 320px 이상, 긴 변 3840px 이하, 긴 변은 짧은 변의 두 배 이하
- 상태 표시줄에서 개인정보·테스터 계정·기기 식별 정보·알림·통신사 이름을 제거해요.
- 실제 다크 테마와 현재 기능만 보여주고 존재하지 않는 화면을 합성하지 않아요.
- 이름만 다른 동일 파일은 여러 장으로 인정하지 않으며 로컬 검사에서 차단해요.
- Console 업로드 때 각 이미지에 140자 이하의 한국어 대체 텍스트를 입력해요.

로컬 검증기는 JPEG의 마커 구조·크기·RGB 메타데이터까지만 확인하고 엔트로피 픽셀은 디코딩하지 않아요. JPEG를 사용하면 Play Console 업로드와 미리보기에서 실제로 정상 표시되는지도 반드시 확인해요.

업로드 전에 저장소 루트에서 `npm run release:verify:play-store-assets`를 실행해요. 이 README는 이미지 수에 포함되지 않아요.
