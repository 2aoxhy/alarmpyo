# Google Play 휴대전화 스크린샷

V08 Play 설치본을 실제 Android 기기에 설치한 뒤 이 폴더의 `manifest.json` 순서대로 새로 촬영해요. 현재 manifest 상태는 `recapture-required`이며 최종 스크린샷은 아직 만들지 않았어요. 첨부 경로가 사라진 파일, 웹 미리보기, 이전 버전 이미지나 저해상도 대체 이미지를 게시 자산으로 사용하지 않아요.

확정 노출 순서와 재촬영 원본 이름은 다음과 같아요.

1. `01-brand.webp`: 실제 V08 시작 화면
2. `02-today.webp`: 알람이 준비된 오늘 화면
3. `03-timer.webp`: 실행 중인 30분 타이머
4. `04-settings.webp`: 설정 첫 화면

네 원본을 별도 폴더에 모은 다음 저장소 루트에서 다음 명령을 실행해요.

```powershell
npm run assets:play:screenshots:prepare -- --source-dir "<V08 WebP 원본 폴더>"
```

변환기는 폭 1080px·높이 1920px 이상인 단일 프레임 WebP만 받아요. 정확히 1080×1920인 원본은 픽셀 배치를 그대로 유지하고, 더 크거나 긴 원본은 자르거나 왜곡하지 않은 채 `contain`으로 축소해 `#101214` 배경의 1080×1920 캔버스에 배치해요. 저해상도 원본은 확대하지 않아요. 알파 없는 비인터레이스 RGB PNG로 결정적으로 변환한 뒤 `01-brand.png`, `02-today.png`, `03-timer.png`, `04-settings.png`를 만들며, 네 파일 검증이 모두 끝나야 manifest 상태를 `ready`로 바꿔요.

- 게시 최소: 2장, 최대 8장
- 권장: 1080×1920px 9:16 세로 이미지 4장 이상
- 형식: 채널당 8비트 RGB 3채널 JPEG 또는 알파 채널이 없는 비인터레이스 24비트 RGB PNG
- 허용 크기: 짧은 변 320px 이상, 긴 변 3840px 이하, 긴 변은 짧은 변의 두 배 이하
- 상태 표시줄에서 개인정보·테스터 계정·기기 식별 정보·알림·통신사 이름을 제거해요.
- 실제 다크 테마와 현재 기능만 보여주고 존재하지 않는 화면을 합성하지 않아요.
- 이름만 다른 동일 파일은 여러 장으로 인정하지 않으며 로컬 검사에서 차단해요.
- Console 업로드 때 `manifest.json`의 140자 이하 한국어 대체 텍스트를 같은 순서로 입력해요.

로컬 검증기는 JPEG의 마커 구조·크기·RGB 메타데이터까지만 확인하고 엔트로피 픽셀은 디코딩하지 않아요. JPEG를 사용하면 Play Console 업로드와 미리보기에서 실제로 정상 표시되는지도 반드시 확인해요.

업로드 전에 저장소 루트에서 `npm run release:verify:play-store-assets`를 실행해요. 재촬영 전에는 이 명령이 의도적으로 실패하며, `--allow-missing-screenshots`는 AAB 준비 중 누락 경고를 확인하는 용도로만 사용해요. README와 manifest는 이미지 수에 포함되지 않아요.
