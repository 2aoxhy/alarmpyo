알람표 개인정보 처리방침

시행일 2026년 8월 21일

1. 기본 원칙

알람표는 계정을 만들지 않으며 광고·사용자 분석 도구를 사용하지 않습니다. 근무표, 알람·타이머 설정, 메모와 화면 설정은 사용자의 기기 안에 저장합니다.

2. 기기에 저장하는 정보

  • 근무 방식, 근무 시간과 기준 날짜
  • 사용자가 변경한 일정과 메모
  • 알람·타이머·기상 시간·테마·위젯 설정
  • 사용자가 켠 환경 브리핑의 지역 격자와 마지막 날씨·공기질 결과
  • 백업과 복구에 필요한 앱 설정

근무표·메모·알람·타이머 설정과 출퇴근 시각은 환경 브리핑 서버로 전송하지 않습니다.

3. 사용자가 직접 공유하는 정보

백업 또는 근무 설정 공유를 직접 선택한 경우에만 사용자가 고른 앱이나 저장 위치로 파일을 전달합니다. 공유된 파일은 선택한 서비스의 정책에 따라 처리되며, 저장한 위치에서 사용자가 직접 삭제할 수 있습니다.

4. 업데이트 서비스가 처리할 수 있는 기술 정보

앱은 실행할 때 Expo의 EAS Update 서버에 HTTPS로 호환되는 업데이트가 있는지 확인할 수 있습니다. 이 과정에서 Expo가 업데이트 제공·보안·오류 확인과 서비스 운영을 위해 다음 기술 정보를 처리할 수 있습니다.

  • 기기 운영체제와 앱·런타임 버전, Expo 프로젝트 식별자
  • 업데이트 요청을 구분하는 무작위 설치 토큰
  • IP 주소와 네트워크 요청 정보
  • 업데이트 설치 실패와 성능 진단 정보

개발자는 이 정보를 광고에 사용하거나 판매하지 않습니다. Expo의 처리·보관·삭제 기준은 Expo 개인정보 처리방침과 Expo 개인정보 설명에서 확인할 수 있습니다.

5. 공식 패턴과 공개 방침 호스팅

사용자가 근무 패턴 보관함을 열거나 새로고침하면 앱은 GitHub Pages에서 전자서명된 공식 근무 패턴 세 파일을 HTTPS로 조회합니다. 백그라운드에서 주기적으로 조회하지 않으며, 기기에 저장된 근무표·메모·알람·타이머 설정을 요청에 포함하지 않습니다.

이 방침을 열거나 공식 패턴을 조회하면 GitHub가 서비스의 보안과 무결성을 유지하기 위해 로그인 여부와 관계없이 방문자의 IP 주소를 기록하고 저장할 수 있습니다. 자세한 기준은 GitHub Pages 안내와 GitHub 개인정보처리방침에서 확인할 수 있습니다.

6. 날씨·공기질과 대략적 위치

사용자가 환경 브리핑에서 현재 위치 사용을 직접 선택한 경우에만 앱이 보이는 동안 초기 설정이나 새로고침에 필요한 때 대략적인 위치를 확인합니다. 원 위·경도는 기기에서 기상청 5km 격자로 바꾼 뒤 폐기하며 저장하거나 서버로 보내지 않습니다. 위치 권한을 거부해도 대표 지역을 직접 선택할 수 있습니다.

선택한 격자와 네트워크 IP는 Cloudflare 기반 중계 서버가 기상청 단기예보와 한국환경공단 에어코리아 실측 공기질을 조회·캐시하고 서비스 남용을 막는 동안 처리할 수 있습니다. 근무표와 출퇴근 시각은 요청에 포함하지 않습니다. 기상청·에어코리아 인증키는 중계 서버의 비밀 저장소에만 보관합니다.

기능을 끄거나 앱 데이터를 초기화하면 기기에 저장한 지역 격자와 환경 캐시를 삭제합니다. 공급자 자료에는 발표·관측시각을 함께 표시하며, 공기질은 미래 예측이 아닌 측정소의 현재 실측값입니다.

7. 수면 안내와 건강 정보

수면 준비 시점은 기기에 저장된 근무 일정으로만 계산합니다. 수면 패턴·수면 질·건강 상태나 신체 센서 정보를 입력받거나 측정·기록·전송하지 않습니다. 알람표는 의료기기가 아니며 질환을 진단·치료·치유·예방하지 않습니다. 의료 조언이 필요한 경우 의료 전문가와 상담하는 것이 좋습니다.

8. 권한 사용

  • 알림·정확한 알람·전체 화면 알람: 근무·타이머 알람 전달
  • 진동·알람음 재생: 근무·타이머 알람 동작
  • 부팅 완료 감지: 재부팅 후 예약된 알람 복구
  • 대략적 위치: 사용자가 요청한 지역의 날씨와 공기질 확인
  • 파일 선택: 사용자가 직접 고른 백업 파일 읽기·저장

권한을 허용하지 않으면 관련 기능만 제한됩니다.

9. 보관과 삭제

설정에서 초기화하면 현재 근무표·메모·설정과 환경 브리핑 지역·캐시가 초기화되고 실행 중인 타이머가 취소되지만, 복구할 수 있도록 초기화 직전 근무 자료를 앱의 내부 안전 백업으로 남깁니다. 환경 브리핑 정보는 근무 자료 백업에 포함하지 않습니다. 앱을 삭제하면 현재 자료와 내부 안전 백업이 함께 삭제됩니다. 외부로 내보낸 백업은 사용자가 저장한 위치에서 직접 삭제해야 합니다. 계정이 없으므로 별도의 계정 삭제 절차는 필요하지 않습니다. Expo가 처리하는 업데이트 기술 정보는 Expo의 보관·삭제 기준을 따릅니다.

10. 아동의 개인정보

알람표는 아동을 대상으로 개인정보를 수집하지 않습니다.

11. 문의

개인정보 관련 문의는 앱을 설치한 스토어에 표시된 개발자 연락처로 문의할 수 있습니다. 보안 취약점은 공개 저장소의 비공개 보안 신고 기능으로 신고할 수 있습니다.

12. 방침 변경

내용이 변경되면 이 페이지의 시행일을 수정하고 앱 또는 배포 페이지에서 안내합니다.
