알람표 개인정보 처리방침

시행일 2026년 8월 11일

1. 기본 원칙

알람표는 계정을 만들지 않으며 광고·사용자 분석 도구를 사용하지 않아요. 근무표, 알람 설정, 메모와 화면 설정은 사용자의 기기 안에 저장해요.

2. 기기에 저장하는 정보

  • 근무 방식, 근무 시간과 기준 날짜
  • 사용자가 변경한 일정과 메모
  • 알람·기상 시간·테마·위젯 설정
  • 백업과 복구에 필요한 앱 설정

이 정보는 개발자 서버로 자동 전송하지 않아요.

3. 사용자가 직접 공유하는 정보

백업 또는 근무 설정 공유를 직접 선택한 경우에만 사용자가 고른 앱이나 저장 위치로 파일을 전달해요. 공유된 파일은 선택한 서비스의 정책에 따라 처리되며, 저장한 위치에서 사용자가 직접 삭제할 수 있어요.

4. 업데이트 서비스가 처리할 수 있는 기술 정보

앱은 Google Play와 Expo 업데이트 서비스를 이용해 새 버전을 확인할 수 있어요. 이 과정에서 서비스 운영에 필요한 다음 기술 정보가 처리될 수 있어요.

  • 기기 운영체제와 앱 버전
  • 업데이트 요청을 구분하는 무작위 설치 토큰
  • IP 주소와 네트워크 요청 정보
  • 업데이트 설치 실패와 성능 진단 정보

이 정보는 업데이트 제공과 오류 확인에 사용되며 광고 목적으로 판매하거나 공유하지 않아요. Expo의 처리 기준은 Expo 개인정보 처리방침에서 확인할 수 있어요.

5. 권한 사용

  • 알림·정확한 알람·전체 화면 알람: 근무 알람 전달
  • 진동·알람음 재생: 알람 동작
  • 부팅 완료 감지: 재부팅 후 예약된 알람 복구
  • 파일 선택: 사용자가 직접 고른 백업 파일 읽기·저장

권한을 허용하지 않으면 관련 기능만 제한돼요.

6. 보관과 삭제

앱 안의 정보는 사용자가 설정에서 초기화하거나 앱을 삭제할 때까지 기기에 보관해요. 외부로 내보낸 백업은 사용자가 저장한 위치에서 직접 삭제해야 해요. 계정이 없으므로 별도의 계정 삭제 절차는 필요하지 않아요.

7. 아동의 개인정보

알람표는 아동을 대상으로 개인정보를 수집하지 않아요.
