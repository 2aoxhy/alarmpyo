알람표 개인정보 처리방침

시행일 2026년 8월 12일

1. 기본 원칙

알람표는 계정을 만들지 않으며 광고·사용자 분석 도구를 사용하지 않아요. 근무표, 알람 설정, 메모와 화면 설정은 사용자의 기기 안에 저장해요.

2. 기기에 저장하는 정보

  • 근무 방식, 근무 시간과 기준 날짜
  • 사용자가 변경한 일정과 메모
  • 알람·기상 시간·테마·위젯 설정
  • 백업과 복구에 필요한 앱 설정

이 정보는 개발자 서버로 자동 전송하지 않아요.

3. 사용자가 직접 공유하는 정보

백업 또는 근무 설정 공유를 직접 선택한 경우에만 사용자가 고른 앱이나 저장 위치로 파일을 전달해요. 공유된 파일은 선택한 서비스의 정책에 따라 처리되며, 저장한 위치에서 사용자가 직접 삭제할 수 있어요.

4. 업데이트 서비스가 처리할 수 있는 기술 정보

앱은 실행할 때 Expo의 EAS Update 서버에 HTTPS로 호환되는 업데이트가 있는지 확인할 수 있어요. 이 과정에서 Expo가 업데이트 제공·보안·오류 확인과 서비스 운영을 위해 다음 기술 정보를 처리할 수 있어요.

  • 기기 운영체제와 앱·런타임 버전, Expo 프로젝트 식별자
  • 업데이트 요청을 구분하는 무작위 설치 토큰
  • IP 주소와 네트워크 요청 정보
  • 업데이트 설치 실패와 성능 진단 정보

개발자는 이 정보를 광고에 사용하거나 판매하지 않아요. Expo의 처리·보관·삭제 기준은 Expo 개인정보 처리방침과 Expo 개인정보 설명에서 확인할 수 있어요.

5. 공개 방침 페이지 호스팅

이 방침을 GitHub Pages 주소에서 열면 GitHub가 서비스의 보안과 무결성을 유지하기 위해 로그인 여부와 관계없이 방문자의 IP 주소를 기록하고 저장해요. 이 처리는 공개 방침 페이지를 방문할 때만 발생하며, 알람표 앱이 근무표·메모·알람 설정을 GitHub로 보내는 것은 아니에요. 자세한 기준은 GitHub Pages 안내와 GitHub 개인정보처리방침에서 확인할 수 있어요.

6. 수면 안내와 건강 정보

수면 준비 시점은 기기에 저장된 근무 일정으로만 계산해요. 수면 패턴·수면 질·건강 상태나 신체 센서 정보를 입력받거나 측정·기록·전송하지 않아요. 알람표는 의료기기가 아니며 질환을 진단·치료·치유·예방하지 않아요. 의료 조언이 필요하면 의료 전문가와 상담하세요.

7. 권한 사용

  • 알림·정확한 알람·전체 화면 알람: 근무 알람 전달
  • 진동·알람음 재생: 알람 동작
  • 부팅 완료 감지: 재부팅 후 예약된 알람 복구
  • 파일 선택: 사용자가 직접 고른 백업 파일 읽기·저장

권한을 허용하지 않으면 관련 기능만 제한돼요.

8. 보관과 삭제

설정에서 초기화하면 현재 근무표·메모·설정은 초기화되지만, 복구할 수 있도록 초기화 직전 자료를 앱 내부 안전 백업으로 남겨요. 앱을 삭제하면 현재 자료와 내부 안전 백업이 함께 삭제돼요. 외부로 내보낸 백업은 사용자가 저장한 위치에서 직접 삭제해야 해요. 계정이 없으므로 별도의 계정 삭제 절차는 필요하지 않아요. Expo가 처리하는 업데이트 기술 정보는 Expo의 보관·삭제 기준을 따라요.

9. 아동의 개인정보

알람표는 아동을 대상으로 개인정보를 수집하지 않아요.
